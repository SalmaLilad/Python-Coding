# Python Game Projects

This folder is part of my computer science and engineering learning portfolio.

It contains a selection of Python games built to explore programming concepts, user input handling, game logic, and graphical or console-based interactivity.

## Projects Included
- `rock_paper_scissors_game.py`: A classic Rock-Paper-Scissors game implemented with functions and interactive user prompts.  
- `stick_game_with_functions.py`: A console game that uses functions to manage game rules, turns, scoring, and user feedback.  
- Additional game scripts explore themes such as turn-based play, RNG (random number generation), interactive loops, and simple GUI or console output.

## Technologies & Tools
- Python  
- VS Code, Jupyter, or Replit as editors  
- Core libraries: `random`, `time`, `sys`, `os` for game logic  
- Version control using Git & GitHub

## Learning Outcomes
Through these game projects, I have:
- Gained hands-on experience in structuring code using functions, loops, and conditionals  
- Learned how to manage game state, user input, and output formatting  
- Enhanced debugging, readability, and modularity in Python code  
- Built confidence in turning small ideas into working interactive programs
